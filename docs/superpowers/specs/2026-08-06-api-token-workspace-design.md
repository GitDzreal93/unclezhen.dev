# API Token 工作区与文档面板设计

## 目标

重构 `/admin/api-tokens`，让宽屏页面的右侧区域承担可阅读、可导出的 API 文档，而不是留白；同时保持 Token 创建、密钥提示与 Token 管理操作清晰可用。

## 布局

- 宽度大于 1100px 时，主区域采用两栏网格：左栏为 Token 工作区，右栏为 API 文档面板。左栏最小宽度 420px，右栏最小宽度 500px，文档栏略宽于操作栏。
- 左栏中的“创建 Token”“一次性密钥提示”“已创建 Token”按垂直顺序显示，板块之间间距为 16px。
- 右栏为 sticky 文档面板，顶部与页面标题对齐；面板内部独立滚动，最大高度为视口高度减去页面上下留白。
- 在 1100px 及以下，布局切换为单栏：Token 工作区在上，文档面板在下。文档面板不再 sticky，完整内容自然参与页面滚动。

## 文档与导出

- `docs/api.md` 是文档唯一来源。
- 服务端读取该 Markdown，以现有 `renderMarkdown` 净化并渲染为 HTML，传入 API Token 客户端组件展示。
- 文档区包含标题、简短说明、锚点导航（鉴权、端点、数据字段、示例、错误码）和“导出 .md”按钮。
- 导出按钮在浏览器创建 UTF-8 `text/markdown` Blob 并下载为 `public-content-api.md`；下载内容与右栏渲染内容来自同一 Markdown 字符串。
- 生产 Docker 镜像将 `docs/` 复制到运行镜像，保证动态服务端渲染能读取同一文档。

## 视觉与交互

- 延续后台的深色、紧凑控制台语气，但让板块有清晰节奏：统一 16px 的卡片间距、12–16px 的卡片内边距，以及标题到正文的 8px 间距。
- 文档栏使用较低对比度的背景层与轻边框区分阅读区；端点表、代码块与 scope 标签复用现有强调绿和等宽字。
- 导出按钮有可见文字标签与下载图标语义；文档导航锚点可键盘聚焦。

## 失败与边界

- 文档读取失败时，页面仍保留 Token 管理功能；文档栏显示明确的不可用提示，导出按钮不可用。
- 不增加公开、未鉴权的文档接口；下载在受 middleware 保护的后台页面内由浏览器完成。
- 不更改 Token 生成、撤销、删除或 scope 授权逻辑。

## 验证

- 自动化浏览器验证登录后台后，确认宽屏双栏、文档标题/表格/代码块、Markdown 导出按钮和下载内容。
- 对 Markdown 读取与渲染路径做最小单元验证，覆盖正常文档与读取失败的降级状态。
- 执行生产构建，确认独立部署构建成功。
